# Regime Detection Engine — Dashboard

## Setup

```bash
uv sync
```

## Run

```bash
streamlit run app/streamlit_app.py
```

Open http://localhost:8501 in your browser.

## Usage

1. Select an asset from the sidebar (requires `uv run rde run --config configs/<asset>.yaml --signal` to generate results)
2. Use the section controls to show/hide panels
